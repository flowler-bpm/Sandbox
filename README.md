# Sandbox

## Zehnfinger-Trainer

`zehnfinger.html` ist ein Lernprogramm für das 10-Finger-System. Es läuft komplett im Browser:
Datei herunterladen und per Doppelklick öffnen, keine Installation nötig.

- 12 aufbauende Buchstaben-Lektionen ab der Grundreihe (a s d f – j k l ö),
  danach Grossbuchstaben, Zahlen, Satzzeichen und ganze Sätze
- Bildschirmtastatur (Schweiz oder Deutschland) mit farbigen Fingerzonen; die nächste Taste
  und der richtige Finger werden angezeigt, inklusive Umschalttaste der anderen Hand
- Live-Statistik: Anschläge pro Minute, Genauigkeit, Fehler, Zeit
- Sterne pro Lektion (90 / 95 / 98 % Genauigkeit), Bestwerte und Verlauf
- Fehlerkarte und eine Schwachstellen-Übung mit den Tasten, die am häufigsten danebengehen
- Eigene Texte üben

Bedienung: einfach lostippen. `Esc` erzeugt einen neuen Text, `Enter` nach dem Ende geht weiter.
Der Fortschritt wird im Browser (localStorage) gespeichert.
