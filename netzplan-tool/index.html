Legende & Notation

Jedes Lieferergebnis wird als 5-Felder-Kasten dargestellt:
FAZ
Frühester Anfangszeitpunkt
D
Dauer des Vorgangs (Tage)
FEZ
Frühester Endzeitpunkt
SAZ
Spätester Anfangszeitpunkt
GP
Gesamtpuffer
SEZ
Spätestester Endzeitpunkt
Roter Rahmen / rote Pfeile = kritischer Pfad (Gesamtpuffer = 0)
Graue Pfeile = unkritische Abhängigkeit mit Pufferzeit
→ → → gestrichelte Pfeile = Abhängigkeit zwischen zwei Projekten
